# 家計簿

支出を項目ごとに記録し、月ごとの前月比、年間グラフ、目標金額との差を確認できる家計簿アプリです。

- 記録は、はじめはお使いのブラウザの中だけに保存されます。
- 「ログイン・新規登録」から合言葉（6文字以上）を決めると、Supabaseに記録を保存できます。スマホとパソコンで同じ記録を見られます。
- スマホのブラウザで開いて「ホーム画面に追加」を選ぶと、アプリのように使えます。

## クラウド保存のしくみ

- 合言葉はブラウザの中で鍵に変換し、鍵だけを送ります。合言葉そのものは送りません。
- テーブルは直接読み書きできず、決めた関数（`kakeibo_*`）だけが使えます。
- 合言葉を忘れると、記録を取り出せません。
